## Remaining acceptance and limits

Other official generator stacks, Flutter/native mobile, Helm/Compose/Ansible/OpenTofu/
Kustomize variants, Windows/Linux SDK execution and actual provider budgets remain
open. The configured CI matrix is not evidence those remote jobs executed. Windows
fixtures use command wrappers; the running-wrapper drift case is POSIX-specific.
All new authored modules are below 1,000 lines; the existing 137-line infrastructure
`specs` function remains a static cohesion warning, with no new duplication finding.

The model still has only the existing controlled tools. Native generators, package
managers and validators have normal host privileges and may read configuration,
SDK caches, plugins or network; these controls are not OS containment. Local tool
binding covers selected executable/environment bytes, not every runtime dependency.
No real quota saving or full compatibility is claimed.

Scopes and review payloads remain bounded; source copies obey the existing selected
20-path task scope. Existing files are preserved, including `.gitignore`. Private
pending operations are retained without automated replay/reconciliation. RDD checks,
independent review, methodology approval and deployment remain separate controls.
