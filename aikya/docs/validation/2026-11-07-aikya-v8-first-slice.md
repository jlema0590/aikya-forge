## Regression execution

The first broad run inherited the developer's Claude settings. A targeted
rerun of `test_agent_loop_adversarial.py` in that same personal environment
reported one failure and 21 errors across 13 declared tests/subtests, primarily
`Configured hooks require explicit review with hooks_approved=true`. The broad
personal-environment run was interrupted rather than weakening that permission
check. No personal settings were modified.

The isolated full run completed 716 declared tests in 1044.775 seconds:
708 passed, two skipped, two failed and four errored. This was not a green run.
The affected tests were:

- `test_generated_adapter_distribution.GeneratedAdapterDistribution.test_wheel_builds_without_root_adapters_and_contains_canonical_resources`: inherited PYTHONPATH exposed source distribution metadata to pip, causing an install skip before an isolated import.
- `test_memory_integration.MemoryIntegrationTests.test_live_client_reuses_session_observer_and_releases_only_its_lease`: the local server could not start under the execution restrictions.
- `test_memory_live.MemoryLiveTests.test_authorized_snapshot_uses_latest_complete_publication`, `test_custom_html_or_torn_report_is_not_served_as_current`, `test_loopback_startup_does_not_require_hostname_resolution`, and `test_no_arbitrary_paths_foreign_host_origin_or_missing_capability`: loopback bind raised `PermissionError`.

A follow-up removed inherited PYTHONPATH, used an editable installation in the
temporary test environment and allowed loopback servers. All 15 tests in the three
affected modules passed in 23.097 seconds. The 13 agent-loop adversarial tests
also passed with temporary user settings. No product permission checks were
weakened to achieve these results. The entire suite was not repeated after these
environment corrections; its failed run and successful targeted reruns remain
separate evidence. The newest bridge run separately passed all 11 tests.
