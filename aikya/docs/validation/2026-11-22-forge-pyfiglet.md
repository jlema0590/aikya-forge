# Forge startup wordmark with pyfiglet

This supersedes the cell-based runtime rendering in the historical
[brand report](2026-11-22-forge-brand.md). The original PNG and sampled Aikya palette
remain unchanged. The runtime now renders actual pyfiglet output; no bitmap or
precomputed ASCII substitute is shipped in its place.

## Scope and behavior

pyfiglet 1.0.4 generates the fixed word Aikya in slant/small fonts. The isolated
Python helper emits bounded ASCII JSON. The TUI caches one result per interpreter
per process, chooses a whole font variant that fits, and retains the readable
Harness/Forge/version identity. Narrow widths and helper/dependency failures use
plain text. Repaints and settings do not run inference or reinstall dependencies.

Native builds preflight the reviewed universal wheel's origin/SHA-256 before
creating the payload. The embedded interpreter must actually render both variants
before sealing. Original font files and their attribution headers plus the upstream
license remain installed. Dependency-free core wheels retain plain text; source
terminal installs use `.[terminal]`.
