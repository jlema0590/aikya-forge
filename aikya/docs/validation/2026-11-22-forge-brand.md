## Behavior and compatibility

New projects use `aikya`. Existing console preferences and a legacy theme.json
retain their previous selection. Palette overrides and reset are supported; both
Settings → Appearance and `/aikya-theme aikya` reuse the local theme authority.
The theme changes presentation only, without changing provider, budget, permissions,
agent tools or model context. The logo is not inserted into prompts/transcripts.

The startup display is a terminal-cell rendition of the original connected symbol,
with native readable Harness/Forge labels. The full original PNG remains bundled
for provenance; the display does not claim to reproduce its original resolution.
A bounded stdlib contributor script samples a source viewport into immutable RGB
cell data. The original file is not edited. Runtime verifies the original hash and
uses precomputed cells, requiring neither image protocol nor startup decoder or
external executable. Widths below 60 columns use text; invalid display data also
falls back to text without disabling the operator terminal.
