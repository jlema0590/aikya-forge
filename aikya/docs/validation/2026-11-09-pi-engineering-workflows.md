## Boundaries exercised

Architecture inspection captures bounded selected source. Recordings require exact
current line excerpts/hashes, label supplied interpretations separately from runtime
proof and reuse canonical confirmed document updates. Private/missing/stale excerpts,
wrong lines and unknown runtime-verification kinds are refused; unrelated sections
and custom pages remain protected.

Bug status derives from native execution witnesses, valid failing regression counts,
unchanged-test Red/Green lineage and current independent admission. Environment/
zero-test/unreproduced/stale outcomes cannot certify a fix. Reports match observed
intent/scope when evidence is selected; borrowed author/intent and supplied evidence
assertions are refused. Canonical unique-ID appends preserve previous reports and
signed page ownership with a single localized footer/index.

Mobile planning reads selected platform/framework and command presence without
executing wrappers. ODD uses optional typed context in the existing state/template;
SDD signs that context in its existing task selection. Unselected platform paths,
unapproved stages and changed context are refused; reselection invalidates prior
source grants. Presence, compatibility, build/tests and simulator/device acceptance
remain distinct. Existing generic ODD features are preserved rather than silently
adopted into a new platform context. Embedded footer fields fail before effects.

## Remaining limits

Native engineering commands expose explicit metadata/evidence workflows. They do not
implicitly fix source, draft findings with a model, execute arbitrary SDKs or grant
workflow/delivery authority from prose. Source changes, checks and independently
budgeted review retain the existing guarded operations.

Bug registers retain the existing 12 KB native rendered-page bound and require
reviewed archival before exceeding it. Reported fixes are snapshots; living-page
writes change full candidate identity and do not transfer an earlier acceptance.
The B plan tracks documented continuity/recovery without silently excluding controls.

Mobile build/test/simulator/device, real framework versions, Windows/Linux runtime
acceptance and actual providers remain separate gates. Metadata fixtures and a
configured CI matrix do not certify these. SDK presence checks retain ordinary local
machine trust and do not establish operating-system containment.

Managed distribution/runtime migration, larger operations, native skill lifecycle,
long-session/provider acceptance and final v8 release remain open. Newly changed
source modules are below 1,000 lines with no static quality errors/warnings or
nontrivial duplicate-body finding in the inspected diff.
