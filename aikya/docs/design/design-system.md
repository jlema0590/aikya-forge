## Structure and interaction

The explorer has source navigation, the main view and a provenance inspector.
Knowledge graph, Architecture and Inventory are mutually exclusive main views;
Inventory hides the graph SVG and retains pagination and row keyboard interaction.
Search, source filters and the inspector retain full paths/names when drawing
limits or progressive expansion omit labels from the graph.

Graph views support pan, anchored zoom, fit/reset and individual object dragging.
Manual positions are per-view in-memory presentation state, preserved across
filters/live snapshots while open; they do not change source, index or approvals.
Focused nodes can be moved with arrow keys, and Escape cancels dragging.

## Forge terminal identity

The `aikya` terminal theme uses colors sampled from the first-party Harness PNG:
navy `#0b1f44` (source pixel 646,506), cyan `#0fb3f1` (160,650) and turquoise
`#1fccba` (408,583). Supporting text `#edf4ff`, muted `#acbed6`, panel `#112139`
and border `#29405e` reuse the existing viewer tokens above. The viewer keeps its
own documented navy background; the Forge theme is a separate presentation.

The original [Harness artwork](../../../docs/images/aikya-harness.png) remains
unchanged in docs/images/. Forge renders a terminal wordmark using pyfiglet 1.0.4
and fixed slant/small ASCII fonts, with readable native Harness/Forge labels.
The runtime does not duplicate or decode the PNG. Compact widths use plain text.
This is a terminal wordmark, with the original artwork retained as brand reference.

New projects default to Aikya; explicit existing preferences are preserved.
