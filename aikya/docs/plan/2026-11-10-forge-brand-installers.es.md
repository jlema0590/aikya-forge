**Objetivo:** usar Aikya Forge como marca y nombre de distribución nuevos, y generar
instaladores sencillos para macOS, Windows y Linux con el runtime incluido.

**Arquitectura:** mantener el núcleo Python, los comandos `aikya` y el motor de
instalación administrada. Actualizar marca y empaquetado de forma coherente, añadir
accesos de instalación por plataforma y construir cada paquete en su sistema nativo.

**Tecnologías:** Python 3.10–3.13, shell POSIX, PowerShell, Node/Pi y GitHub Actions.

**Requisitos:** petición del usuario de sustituir Harness por Forge y generar un
instalador simple para los tres sistemas; [revisión y línea base](../research/2026-11-10-forge-brand-installers.es.md).

## Foco de revisión

1. Wheel renombrado: instalación y preflight resuelven la misma distribución/version.
2. Proyecto heredado: firmas antiguas siguen reconocidas y datos personalizados
   permanecen protegidos durante una actualización.
3. Rutas con espacios o caracteres no ASCII: accesos de instalación mantienen
   argumentos, seleccionan el payload correcto y propagan el código de salida.
4. Descarga ausente/corrupta o arquitectura sin paquete: terminar con error claro
   antes de ejecutar intérpretes o modificar una instalación existente.
5. Fallo de una plataforma de CI: no presentar el conjunto incompleto como soporte
   multiplataforma validado ni publicar automáticamente resultados.
