# Métricas de Claude y Codex en el panel derecho

**Objetivo:** mostrar Context, Tokens, Usage 5h y Usage 7d por proveedor, junto al
bloque Project & Git y al límite local de Aikya, en la terminal y ejemplo visual.
**Arquitectura:** un renderer puro por proveedor recibe el ledger local, contexto
SDK con proveedor explícito y observaciones de cuotas existentes. No añade llamadas
remotas, lectura de credenciales ni cambios al presupuesto de ejecución.
**Tecnologías:** Pi 1.5.0, TypeScript/Node >=22.19.0 y cuotas observadas en cabeceras.
**Especificación:** petición del usuario sobre contexto/tokens/5h/7 días y aclaración
sobre qué significa local budget.

## Semántica y límites

- Context pertenece a la sesión activa del proveedor y es una estimación del SDK.
  No se replica entre Claude y Codex ni se infiere el contexto del revisor aislado.
- Tokens son totales registrados de ese proveedor en el proyecto, no una ventana
  de cuota ni un coste monetario. Datos parciales conservan la indicación unknown.
- Usage 5h/7d se seleccionan por duración exacta (18000/604800 segundos), nunca por
  el nombre primary/secondary. Se conserva cero válido, fuente, antigüedad y stale.
- Local budget es el límite configurable de tokens/llamadas de Aikya por proyecto.
  No representa el saldo, suscripción ni límites de la cuenta del proveedor.
- Sin evidencia se indica unavailable; no se consulta ningún endpoint de cuenta ni
  se hace inferencia para rellenar indicadores. El consumo ajeno a Forge solo puede
  reflejarse si está incluido en una observación de cuota del proveedor.
