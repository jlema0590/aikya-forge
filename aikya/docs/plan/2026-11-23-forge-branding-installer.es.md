# Identidad Forge e instalación corta

**Objetivo:** unificar la marca activa, distribución Python y documentos nuevos en
Aikya Forge, y ofrecer instalación nativa con un comando sin clonar ni preparar
Python/Node. Documentar comandos reales y su estado de publicación.
**Arquitectura:** los bootstrap de entrada resuelven la release estable y verifican
SHA-256 del instalador versionado existente antes de delegar. Se reutilizan sus
plataformas, descarga de runtimes, instalación, actualización y controles de propiedad.
**Tecnologías:** shell POSIX, PowerShell, Python >=3.10, instaladores nativos existentes.
**Especificación:** petición explícita de sustituir Aikya Harness por Aikya Forge,
retirar referencias operativas a Milkeles y simplificar/documentar la instalación.

## Límites y compatibilidad

El paquete nuevo es aikya-forge; los comandos aikya/aikya-manage/aikya-setup siguen
siendo válidos. La firma canónica nueva es GENERATED BY AIKYA FORGE. Se conserva
lectura de marcas antiguas para reconocer documentos/memorias propios y proteger
contenido personalizado. Datos de migración, licencias/procedencia y evidencias
históricas conservan los identificadores originales cuando sean necesarios.
No se reescriben hashes históricos ni autores/URLs de procedencia como si fueran de
Forge. Las workflows antiguas de publicación permanecen desactivadas; el renombrado
no habilita publicaciones automáticas. No se registra/publica un paquete npm.

La consulta pública inicial devolvió 404 para release latest y paquete npm. El
README debe explicar que el comando de instalación requiere una release estable
publicada; los tests usarán artefactos offline controlados, sin fabricar disponibilidad.
