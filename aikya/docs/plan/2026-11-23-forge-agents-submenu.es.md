# Submenú Agents en el panel derecho

**Objetivo:** agrupar Claude y Codex con sus métricas dentro de un submenú
Agents desplegable, disponible en la terminal y en el ejemplo visual.
**Arquitectura:** estado de presentación por sesión controla la expansión del
renderer. El workbench identifica la fila Agents para clicks y la TUI registra
F3 más una opción en F2 → Agents. No se cambian observación ni ejecución de IA.
**Tecnologías:** Pi 1.5.0, TypeScript/Node >=22.19.0 y métricas existentes.
**Especificación:** petición del usuario de mover Claude/Codex a un submenú Agent.

## Comportamiento

Agents comienza expandido para conservar la visibilidad de las métricas. Se puede
plegar con click, F3 o F2 → Agents. El estado solo dura la sesión y no modifica la
configuración de proveedores, la selección de modelos, el presupuesto o permisos.
Al plegar se ocultan ambos bloques y al abrir reaparecen con los datos actuales.
El resumen compacto ofrece acceso por F3/F2 y muestra el estado del submenú.
