## Changes

src/aikya/review/process.py permits a bounded 200 ms reap after Darwin denies a signal
while an already-finishing child changes state. A child which remains live still
raises the original denial. Payload sealing reuses the existing bounded no-link walk
from src/aikya/installation/managed_runtime.py instead of rewalking every ancestor for
every file. Per-file hashes, child checks and full readback remain in place.

processes, based on observed ARM build/install duration. Other command limits remain
unchanged. Timeout diagnostics retain the failing step and partial output; container
failure logs are returned to the CI user's ownership. Windows .NET regression reports
changed paths for diagnosis, and its independent-review fixture explicitly reads UTF-8.

The native workflow now runs packaged-input changes on PRs and develop; evidence-only
document updates do not rebuild seven unchanged runtimes. README files link to the
current per-platform status instead of fixing an obsolete acceptance statement.
