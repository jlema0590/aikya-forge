# Explicitly selected native skills and pre-dispatch integrity

## Changes

`src/aikya/services/skill_source.py` inspects bounded selected local packages with
existing Agent Skills validation. `selected_skills.py` previews concrete files/hashes,
reserves effects, preserves exact originals and copies data without executing code.
It signs the registry, normalizes the Pi entry for explicit invocation, writes localized
installation/comparison records and exposes bounded current approved resource reads.

`packages/aikya-pi/src/selected-skills.ts` adapts status/plan/install commands and
public Pi skill loading. Discovery remains disabled and source metadata does not
confer tool permissions. Skills are excluded from automatic prompt listings; resource
access requires a verified explicit author invocation and is unavailable to reviewers.
`budgeted-inference.ts` checks the actual expanded payload before dispatch/admission,
because Pi reports hook exceptions without necessarily stopping the request.
