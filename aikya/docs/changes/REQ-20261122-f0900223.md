# Include original Aikya Harness identity in Forge

Add `aikya` as the new-project terminal theme, with navy/cyan/turquoise samples
from the existing first-party logo. Retain already selected themes, personal color
overrides and the legacy preference fallback. Settings and `/aikya-theme aikya`
share the existing project-local persistence and preview/confirmation path.

Bundle the original PNG byte-for-byte and its derived terminal presentation data.
The header renders the original connected symbol in colored cells beside readable
Harness/Forge names, retains Forge version identity and falls back to text at small
widths or if display assets are unavailable. No logo generation, external terminal
image protocol, startup download, image decoder or model call is required.

Three initial SDK regressions revealed an incomplete simulated Theme in the UI
fixture. Replacing it with real pinned Theme objects preserved the tested approval
and task semantics; targeted cases and full Node 22/26 suites passed afterward.
The prior Windows observer-cleanup defect remains separate.

See [brand inclusion validation](../validation/2026-11-22-forge-brand.md) and the
updated design system. This extends draft PR #2 without publishing a release.
