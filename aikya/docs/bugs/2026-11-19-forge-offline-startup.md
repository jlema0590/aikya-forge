# Forge offline interactive startup and host failure evidence

## Observed behavior

The installed macOS ARM 0.2.0 PTY displayed fd not found and deliberately skipped
its download because PI_OFFLINE=1. Pi 1.5.0 probes fd/rg after mounting its UI; fd
supports file autocomplete. The visible version banner was correct but the window
title/help still named v8. Headless native acceptance had not exercised this UI.

Pi's tool manager prefers agent/bin over PATH. A repository-provided executable
there must not acquire startup authority from file existence alone.

## Implementation

The new reviewed catalog fixes official fd 10.5.2/ripgrep 15.2.0 release archives,
SHA-256, target names, versions and executable paths for seven native targets.
Linux uses static musl variants; complete upstream license files remain in payloads.
Prepare verifies bytes before build output. Build and installation preflight probe
actual versions. Managed launch prepends verified payload tool directories to PATH;
startup remains offline and rejects existing project tool caches without changing
or executing them. Both launcher and SDK interactive-runtime entry enforce this.
Window title/help use the installed Forge package version.

Independent review identified Windows' implicit current-directory executable
lookup before PATH and delimiter-containing installation roots. Native entry now
disables the former in the parent Node environment; preflight refuses the latter
before activation. A persistent refusal of task.stop cannot hide the original
diagnostic or claim the host confirmed a stop.

The host protocol now returns only a static failure category and bounded first-party
module/function stage. Node distinguishes timeout/cancellation/unavailable/refusal;
task failure messages retain those safe fields without automatic replay. Exception
text, inputs, stdout, private paths and credentials are not copied into diagnostics.
The Windows final-record intermittence remains unconfirmed until current CI reproduces
its cause; a no-change passing rerun does not prove a production correction.

## Verification to date

All twelve unique official archives were downloaded and matched their GitHub release
digests. Every target's archives staged with retained licenses; only native macOS
ARM executables were run locally (fd 10.5.2, ripgrep 15.2.0 with revision suffix).
Mach-O headers report macOS 11.0 minimum; Linux samples are static ELF. These data
checks are not acceptance of executing every target.

Seven tool-input contracts, three host privacy contracts, the real SDK title/cache
and failure tests pass locally. The complete SDK battery passed 98 tests before
extending the cache guard to the SDK runtime factory; focused tests and a minimum-
Node full rerun cover that extension. Full revised native acceptance is still pending.
