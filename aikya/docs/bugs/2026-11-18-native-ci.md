# Native CI cross-platform corrections

The first Forge PR run exposed these concrete failures:

- Linux GNU x64/ARM and musl rejected official Python terminfo names such as
  share/terminfo/P/P12 and share/terminfo/p/p12 as portable case aliases. Native Linux
  archives/manifests now preserve case-sensitive names explicitly. Generic packages,
  macOS and Windows keep their default case-insensitive alias protection. Unicode
  normalization aliases, traversal, device names, duplicate roles, parent conflicts,
  link bounds, hashes and no-overwrite writes remain guarded. Linux payloads require
  a filesystem capable of preserving their names; there is no silent name rewriting
  or omission of terminal data.
- macOS Intel failed a public component download with a DNS URLError. Immutable
  native component/parser reads now have at most three same-origin bounded attempts.
  Missing assets, TLS certificate failures, validation errors and integrity failures
  are not turned into successful downloads. No model/action execution is retried.
- Windows Pi contracts read UTF-8 documents with cp1252, created CRLF fixtures while
  asserting LF bytes, and failed to trigger injected faults using POSIX-only suffixes.
  Their fixtures now specify UTF-8/LF and normalized path comparisons. The synthetic
  CMD tool wrapper returns its actual Python exit code explicitly.
- Actual SDD completion also failed on Windows: generated SDD temporary files used
  platform newline translation while the current-evidence proof expected canonical
  LF. The state writer now emits explicit LF. A failing real completion regression
  with simulated Windows text defaults preceded the fix.

Observed focused results after corrections: 94 managed-runtime tests, 316 native Pi
Python contracts and three component-download tests passed locally. Official GNU x64
Python/Node archives were hash-verified and fully planned without extracting or
executing foreign code. Real remote execution still needs a passing rerun; this
record does not turn the first failed run into native acceptance.
