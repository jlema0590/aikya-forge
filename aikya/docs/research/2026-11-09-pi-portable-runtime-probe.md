Both archives passed byte/hash checks before bounded inspection/extraction. The
Python archive contained 1,657 members and nine links; Node contained 5,828 members
and two links. Contained links were handled by Python's data extraction filter in
this temporary probe; the product's archive/manifest policy still needs implementation.

Move the self-contained Python distribution first, copy the official Node executable
and then create a new environment at its final location containing spaces and Unicode.
The relocated Python reported 3.13.18, loaded venv/ensurepip/SSL, installed the private
C source wheel offline and imported the installed lifecycle module under isolated
Python. Node reported 26.13.0. Aikya help ran from that environment. Eight real-Pi SDK
skill tests also passed against both relocated executables, with local fixture
providers and no real model calls.

A fresh production dependency install used the versioned Node/npm binary, the
repository lock, an empty temporary npm configuration and disabled lifecycle scripts.
It installed 124 packages; npm reported the inherited `node-domexception@1.0.0`
deprecation. Supply-chain/license review remains open; the notice is not a runtime
failure or evidence of security. The copied runtime inventory contains 16,770 regular
files (115,873,711 bytes), eight contained links and 152 package-license records;
these counts describe packaged contents, not 152 independently resolved dependencies.

The copied runtime then opened its real public terminal launcher from `/private/tmp`
with system Node/Python removed from PATH, using only portable binaries, installed
Python host and its own fresh dependencies. Project status/skill status passed,
sessions stayed project-local and shutdown exited normally with zero model calls.
This verifies an independent temporary runtime, not the managed installer/default
`aikya` entry or other operating systems. Raw evidence is in
`independent-terminal.json`/`.raw` beside the relocation record.

The environment was created after choosing its final path. This does not demonstrate
that an arbitrary existing virtual environment can be moved safely. Nor does it
