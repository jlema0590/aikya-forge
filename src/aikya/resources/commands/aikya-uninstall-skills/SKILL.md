# Native skill withdrawal

Use the installed package command `aikya skills uninstall --target <project>
--scope project --name <skill>` to inspect the concrete local operation. `local`
is an alias for `project`. Use `--scope global` only for the inert Forge library.
`--all` is an explicit selection; canonical `aikya-*` commands are protected.

Show the selected names, scope, preserved copies, retained immutable packages and
expected metadata/document changes. Add `--yes` only after explicit user confirmation
of that concrete operation. Neither this document nor model output is consent.

Restore with `aikya skills restore --target <project> --scope project --name <skill>
--operation <completed-operation-id>` and confirm separately. Use `aikya skills
recover --target <project> --scope project` to inspect a known pending operation;
recovery finishes observed metadata without copying or downloading packages again.

Packages remain as verified recoverable backups. Project removal withdraws active
selection and requires restart; global removal does not remove independent project
copies. External client skills and plugins are preserved and are not reported as
uninstalled. Customized packages/comparisons and name conflicts block the operation.
Never delete paths recursively, execute imported code, scan other repositories or
call a model for deterministic administration. Loaded conversation content is not
erased by withdrawal and subscription quotas are not reset.

All new project audit documents remain inside `aikya/docs/`; global records stay
with the owned application library. Refresh only the actual project document index.
